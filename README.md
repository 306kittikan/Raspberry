# ตู้บริการข้อมูลอัจฉริยะ (Smart Kiosk)

UI ตู้บริการข้อมูลของ **สาขาวิชาวิทยาการคอมพิวเตอร์ คณะวิทยาศาสตร์ มหาวิทยาลัยแม่โจ้**
สร้างด้วย React + Tailwind CSS สำหรับรันเต็มจอใน Chromium kiosk mode บน Raspberry Pi 5
ข้อมูลทั้งหมดเป็นข้อมูลจำลอง ไม่มีการเชื่อมต่อกล้อง ไมโครโฟน หรือ API จริง

## เริ่มใช้งาน

```bash
npm install
npm run dev       # พัฒนา
npm run build     # สร้างไฟล์สำหรับใช้งานจริง
npm run preview   # ทดลองรันไฟล์ที่ build แล้ว
```

เปิดเบราว์เซอร์ที่ http://localhost:5173
หน้าจอออกแบบที่ขนาด **1080×1920 (แนวตั้ง)** และย่อให้พอดีหน้าต่างโดยอัตโนมัติขณะพัฒนา

## แผงตัวควบคุมทดสอบ

แตะแถบเล็ก ๆ ที่ **ขอบขวาของจอ (กึ่งกลางแนวตั้ง)** เพื่อเปิดแผงจำลองสถานะ

| กลุ่ม | ปุ่ม |
| --- | --- |
| เซ็นเซอร์ | ตรวจพบคน (ปลุกจอ) · เข้าสู่จอพักลึก |
| ใบหน้า | จำหน้าได้ · จำหน้าไม่ได้ · พบหลายใบหน้า · หาใบหน้าไม่เจอ · กล้องใช้งานไม่ได้ · สลับผู้ใช้ |
| เครือข่าย | ออนไลน์ · ออฟไลน์ |
| เสียง | กำลังฟังเสียง · ฟังไม่ชัด |
| ข้อมูล | ไม่มีข้อมูลตารางเรียน · รีเซ็ตทั้งหมด |

ด้านล่างของแผงแสดงบันทึกการใช้งานล่าสุด ซึ่งถูกเขียนลง console คู่กันด้วย

## โครงสร้างโค้ด

```
src/
├─ App.jsx                 กำหนดเส้นทางหน้าจอทั้ง 11 หน้า + ยามกันหน้าที่ต้องยืนยันตัวตน
├─ state/KioskProvider.jsx สถานะกลาง นาฬิกา ตัวจับเวลา และตัวควบคุมจำลองทั้งหมด
├─ data/mockData.js        นักศึกษา 2 คน ตารางเรียน กำหนดสอบ ประกาศ คำถามยอดนิยม
├─ lib/
│  ├─ time.js              จัดรูปแบบวันที่ไทย + คำนวณคาบเรียนถัดไป/นับถอยหลัง
│  ├─ answers.js           แปลงคำถามเป็นคำตอบ พร้อมระบุแหล่งที่มาเสมอ
│  └─ logger.js            บันทึกการใช้งานลง console
├─ components/             ชิ้นส่วน UI ที่ใช้ซ้ำ (ป้ายแหล่งที่มา ไมโครโฟน แป้นตัวเลข ฯลฯ)
└─ screens/                หน้าจอแต่ละหน้า
```

| ชื่อ | ไฟล์ | หมายเหตุ |

| ถ่ายใบหน้า | `EnrollScreen.jsx` | มีตัวบอกความคืบหน้า |

## ข้อกำหนดที่ฝังไว้ในโค้ด

- **ป้ายบอกที่มาของคำตอบ** — `components/SourceBadge.jsx` แยกด้วยสีและไอคอน
  เขียว/ฐานข้อมูล = “ข้อมูลจากระบบของสาขา” · ม่วง/ประกาย = “ตอบโดยผู้ช่วย AI · อ้างอิง: {เอกสาร}”
- **ห้ามเดาคำตอบ** — เมื่อไม่พบเอกสารอ้างอิง `lib/answers.js` จะคืน “ไม่พบข้อมูลนี้ในระบบ” พร้อมช่องทางติดต่อสาขา
- **ออฟไลน์** — ปิดเฉพาะฟังก์ชัน AI (ปุ่มเป็นสีเทาพร้อมคำอธิบาย) ตารางเรียนยังใช้งานได้
- **ความเป็นส่วนตัว** — แสดงเฉพาะชื่อและรหัส 4 หลักท้าย · ปุ่มออกจากระบบอยู่ทุกหน้า ·
  ไม่ใช้งาน 30 วินาที → นับถอยหลัง 10 วินาที → ล้างข้อมูลบนจอทั้งหมด (`TIMING` ใน `KioskProvider.jsx`)
- **ขนาดตัวอักษร/เป้าแตะ** — เนื้อหา ≥ 24px หัวข้อ ≥ 40px เป้าแตะ ≥ 72×72px (คลาส `.tap` และสเกล `fontSize` ใน `tailwind.config.js`)
- **ประสิทธิภาพบน Raspberry Pi** — ใช้เฉพาะ transition/transform สั้น ๆ ไม่ใช้ blur และ backdrop-filter

## บันทึกการใช้งาน

ทุกครั้งที่ผู้ใช้ถามคำถามหรือเลือกเมนู ระบบเขียน log ลง console โดยไม่มีข้อมูลระบุตัวตน

```js
[kiosk-usage] { เวลา: "2026-09-25T05:24:58.101Z",
                ประเภทคำถาม: "ตารางเรียน",
                ช่องทาง: "เสียง",
                แหล่งคำตอบ: "ฐานข้อมูล" }
```

## รันบน Raspberry Pi 5 (Chromium kiosk mode)

```bash
npm run build
npx serve dist -l 8080        # หรือเสิร์ฟด้วย nginx

chromium-browser \
  --kiosk http://localhost:8080 \
  --noerrdialogs \
  --disable-infobars \
  --disable-pinch \
  --overscroll-history-navigation=0 \
  --check-for-update-interval=31536000
```

ตั้งค่าจอเป็นแนวตั้ง 1080×1920 และปิด screen blanking ด้วย `xset s off -dpms`

หากตู้ต้องทำงานขณะออฟไลน์ ให้ดาวน์โหลดฟอนต์ IBM Plex Sans Thai และ Noto Sans Thai
มาเก็บไว้ในโปรเจกต์แทนการโหลดจาก Google Fonts ใน `index.html`

## สิ่งที่ยังไม่ได้ทำ (ตามขอบเขตที่กำหนด)

- ไม่มีการเชื่อมต่อกล้อง ไมโครโฟน หรือ API จริง — จำลองทั้งหมด
- ไม่มีแดชบอร์ดผู้ดูแลระบบ (แยกทำภายหลัง)
