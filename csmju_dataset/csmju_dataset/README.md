# CSMJU Dataset (v2)

ชุดข้อมูลนี้รวบรวมเนื้อหาสาธารณะทั้งหมดจากเว็บไซต์ **https://gates.csmju.com** (สาขาวิชาวิทยาการคอมพิวเตอร์ คณะวิทยาศาสตร์ มหาวิทยาลัยแม่โจ้) เก็บข้อมูลเมื่อวันที่ 26 กันยายน 2569 และ **v2 (27 ก.ย. 2569)** เพิ่มข้อมูลสาธารณะที่เกี่ยวกับสาขาจากเว็บ **สำนักบริหารและพัฒนาวิชาการ https://edu.mju.ac.th** (ตาราง `edu_*`)

## วิธีเก็บข้อมูล

เว็บไซต์สร้างด้วย Next.js และดึงข้อมูลจาก REST API ที่ `https://gates.csmju.com/api/*` ข้อมูลจึงเก็บจาก 3 แหล่ง:

1. **Public API** ดึงครบทุกหน้า (pagination) จาก 21 endpoint ที่เปิดให้เข้าถึงโดยไม่ต้องล็อกอิน และตรวจแล้วว่าจำนวนระเบียนตรงกับ `meta.totalItems`
2. **หน้าเว็บที่เรนเดอร์จริง** (headless Chromium) ทุกหน้าสาธารณะ รวมทุกแท็บของหน้ารายละเอียดหลักสูตร ส่วนนี้ใช้เก็บเนื้อหาที่เขียนไว้ตายตัวในโค้ด frontend และไม่มีใน API เช่น ปรัชญา วิสัยทัศน์ พันธกิจ วัตถุประสงค์ PLO และตัวเลขสถิติในหน้าแรกและหน้าเกี่ยวกับเรา
3. **ตรวจสอบย้อนกลับ** รหัสวิชาทุกตัวในโครงสร้างหลักสูตรและแผนการศึกษาพบบนหน้าเว็บจริง และหน่วยกิตรวมรายภาคเรียนตรงกับที่หน้าเว็บแสดง

ไม่ได้เก็บส่วนที่ต้องล็อกอิน (`/mis/*`, `/dashboard/*`, endpoint `users`, `complains`)

### แหล่งที่ 2: edu.mju.ac.th (v2)

เว็บสำนักฯ เป็น ASP.NET WebForms ข้อมูลจึงดึงด้วยการจำลองการเลือกตัวเลือกบนฟอร์ม (postback) แบบเดียวกับที่ผู้ใช้กดบนหน้าเว็บ เก็บเฉพาะข้อมูลที่เกี่ยวกับสาขาวิทยาการคอมพิวเตอร์ หรือข้อมูลที่นักศึกษาใช้บ่อย:

- **คำอธิบายรายวิชาทางการ** 201 เวอร์ชันรายวิชา (159 รหัสวิชา) ครอบคลุมทุกรหัสที่อยู่ในหลักสูตร CSMJU, โครงสร้างหลักสูตรทางการ และแผนการศึกษาทางการ แล้วนำมาเติมในตาราง `courses` (คอลัมน์ `official_*`)
- **โครงสร้างหลักสูตรและแผนการศึกษาทางการ** ของรหัสหลักสูตร 65304010 (ปรับปรุง 2565) และ 60304010 (หลักสูตรเดิม)
- **สถิติแบบรวม (aggregate):** จำนวนรับเข้า อัตราสำเร็จการศึกษา และอัตราคงอยู่รายรุ่นของสาขา จำนวนนักศึกษาปัจจุบันรายคณะและรายหลักสูตร
- **ปฏิทินการศึกษา 2569** (ถอดจาก PDF สแกน และตรวจวันในสัปดาห์ทุกวันที่แล้ว) และ **ตารางสอบปลายภาค 1/2569** เฉพาะวิชาที่เกี่ยวกับหลักสูตร
- **ดัชนีเอกสาร/แบบฟอร์ม/ระเบียบ** 646 รายการ (ชื่อ + ลิงก์ดาวน์โหลด) และ **เบอร์ติดต่อแยกตามงานบริการ** ของสำนักฯ

**ไม่ได้เก็บโดยเจตนา:** รายชื่อนักศึกษา (StudentList), รายชื่อผู้สำเร็จการศึกษา (GraduateList), ชื่อผู้กำกับห้องสอบในไฟล์ตารางสอบ และระบบที่ต้องล็อกอิน (Student / informationSystem / Parent / reg.mju.ac.th) เพราะเป็นข้อมูลส่วนบุคคลหรือต้องใช้บัญชีผู้ใช้

## โครงสร้างไฟล์

```
csmju_dataset/
├── csmju_dataset.json          ← ข้อมูลทั้งหมดในไฟล์เดียว (meta + organization + ทุกตาราง)
├── csv/                        ← 33 ตาราง (21 จาก CSMJU + 12 ตาราง edu_*) (UTF-8 with BOM เปิดใน Excel ได้ภาษาไทยไม่เพี้ยน)
├── rag/csmju_knowledge_chunks.jsonl  ← 549 chunks ภาษาไทยพร้อมใช้กับ Chatbot / RAG / embedding
├── raw_api/                    ← JSON ดิบจาก API ของ gates.csmju.com
└── raw_edu/                    ← ข้อมูลดิบจาก edu.mju.ac.th (คำอธิบายรายวิชา, รายการวิชาทั้งมหาวิทยาลัย, ดัชนีเอกสาร, ไฟล์ตารางสอบ, PDF ปฏิทิน)
```

## ข้อสังเกตเกี่ยวกับข้อมูลต้นทาง (ควรรู้ก่อนนำไปใช้)

1. **ปีก่อตั้งไม่ตรงกัน:** ไทม์ไลน์ในหน้าเกี่ยวกับเราระบุ "1995" และ "2010" แต่เนื้อหาประวัติใน API ระบุว่าเริ่มตั้งภาควิชาปีการศึกษา 2536 (ค.ศ. 1993) และรับนักศึกษารุ่นแรก 38 คนในปีการศึกษา 2538 (ค.ศ. 1995) ชุดข้อมูลเก็บทั้งสองแบบตามต้นฉบับ
2. **แผนการศึกษามีหน่วยกิตรวมไม่เท่ากับ 120:** หลักสูตร 2565 รวมได้ 114 หน่วยกิต (ปี 4 ภาค 1 ว่าง) และหลักสูตร 2570 รวมได้ 132 หน่วยกิต ตัวเลขนี้ตรงกับที่หน้าเว็บแสดง จึงน่าจะเป็นข้อมูลต้นทางที่ยังกรอกไม่ครบหรือไม่ตรง
3. **program_courses 71 แถวไม่ผูกกับหลักสูตร** (`program_id` ว่าง) เช่น กลุ่มวิชาเอกบังคับ กลุ่มวิชาแกน และวิทยานิพนธ์ ดูเหมือนเป็นข้อมูลค้าง (orphan) ในฐานข้อมูล ถ้าต้องการเฉพาะที่แสดงบนเว็บ ให้กรองแถวที่ `program_id` ไม่ว่าง
4. **ตัวเลขสถิติไม่ตรงกันระหว่างหน้า:** หน้าแรกระบุผู้สำเร็จการศึกษา "1,999+" ส่วนหน้าเกี่ยวกับเราระบุศิษย์เก่าสาย IT "1,000+"
5. **ส่วนที่ยังไม่มีข้อมูล:** events (ปฏิทินกิจกรรม), alumnis (ศิษย์เก่า) และ testimonials มี 0 รายการ ปุ่ม "ทุนการศึกษา" ในหน้าแรกไม่มีลิงก์
6. บุคลากร 5 คนไม่มีโปรไฟล์ละเอียด (`bio`, `expertise` ฯลฯ ว่าง) หน้าเว็บแสดงข้อมูลบุคลากรผ่าน API สาธารณะ
7. เนื้อหา about_sections หมวด ปรัชญา / ความสำคัญ / วัตถุประสงค์ / PLO-SLO (ระดับสาขา) มาจาก API แต่ไม่ปรากฏในหน้า /abouts ตอนเรนเดอร์แบบปกติ และเป็นคนละชุดกับปรัชญาและ PLO ในหน้ารายละเอียดหลักสูตร (ตาราง programs / program_plos)
8. ห้อง "ห้องคอมพิวเตอร์ 3203 จุฬาภรณ์" มีใน API แต่ไม่แสดงในรายการหน้า Facilities ตอนเก็บข้อมูล
9. **(v2) ข้อมูลหลักสูตรสองเว็บไม่ตรงกัน:** เว็บ CSMJU ระบุโครงสร้างหลักสูตร 2565 ไม่ตรงกับระบบทางการ (edu) ในหลายรายวิชา เช่น 10301141 ในระบบทางการเวอร์ชัน -1 คือ "เครือข่ายคอมพิวเตอร์เบื้องต้น" แต่เว็บ CSMJU ใช้ชื่อ "การพัฒนาเว็บแอปพลิเคชัน" ซึ่งตรงกับเวอร์ชัน -7001 ถ้าจะใช้อ้างอิงทางการ ให้ใช้ตาราง `edu_program_structure` และ `edu_study_plans`
10. **(v2) หลักสูตร 2570 ยังไม่อยู่ในระบบทะเบียน** ตอนเก็บข้อมูล ระบบมีเฉพาะ 65304010 (2565) และ 60304010 (เดิม) บางวิชาของ 2570 มีคำอธิบายแล้ว (เวอร์ชัน -7001)

## ข้อควรระวังในการนำไปใช้

ข้อมูลบุคลากร (อีเมล เบอร์โทร) เป็นข้อมูลติดต่อที่สาขาเผยแพร่สาธารณะ ถ้าจะนำไปเผยแพร่ต่อหรือใช้เชิงพาณิชย์ ควรขออนุญาตสาขาวิชาก่อน เว็บไซต์ตั้ง `meta robots=noindex` ไว้ด้วย

## อัปเดตข้อมูลใหม่

ฝั่ง CSMJU ดึงข้อมูลล่าสุดได้โดยเรียก API โดยตรง เช่น `GET https://gates.csmju.com/api/courses?page=1&limit=100` (ทุก endpoint ส่ง `{data, meta:{totalItems,totalPages}, links}` ยกเว้น `nav-items` ซึ่งส่งเป็น array)

ฝั่ง edu.mju.ac.th ไม่มี API ต้องดึงผ่านฟอร์ม เช่น `CourseDescription.aspx` (เลือกคณะแล้วเลือกรายวิชา), `ProgramStructure.aspx?ProgramID=65304010` และ `studyPlan.aspx?programID=65304010&acadyear=2569` (สองหน้านี้เรียกด้วย GET ได้เลย)
