## ตัวอย่างการใช้บนตู้

```python
import json
from reg_timetable import student_timetable
D = json.load(open("timetable_2569_1.json", encoding="utf-8"))

# ห้องว่างตอนนี้
def free_rooms(day_en, hhmm):
    busy = {(r["building_code"], r["room"]) for r in D["room_timetable"] if r["day_en"] == day_en and r["start"] <= hhmm < r["end"]}
    return [x for x in D["index"]["rooms"] if (x["building_code"], x["room"]) not in busy]

# ตารางสอนอาจารย์
[x for x in D["instructor_timetable"] if "กิตติกร" in x["instructor"]]

# นักศึกษาใส่รหัสของตัวเองที่ตู้ -> ดึงสด ไม่บันทึก
student_timetable("6604101xxx", 2569, 1)["sessions"]
```

## ข้อควรรู้

- `cohort_timetable` เป็นตาราง "ตามแผน" นักศึกษาที่ลงวิชาเอกเลือก ลงล่าช้า หรือเรียนไม่ตรงแผน จะมีตารางจริงต่างออกไป ปี 3–4 แผนการศึกษาส่วนใหญ่เป็นวิชาเลือก จึงไม่มีตารางตายตัว แต่มีรายการวิชาเอกเลือกที่เปิดสอนใน `cohort_course_choices` (`kind = cs_elective_offered`)
- ห้อง "3203" ในข้อมูลวิชาไม่มีรหัสอาคารกำกับชัดเจนในบางกลุ่ม ให้ดูจาก `building_code`
- ภาค 2/2569 ระบบยังไม่เปิดข้อมูล รันสคริปต์เก็บข้อมูลใหม่เมื่อเปิดแล้ว
- ห้อง `room_timetable` แสดงเฉพาะคาบเรียนตามตาราง ไม่รวมการจองห้องเพื่อใช้งานอื่น (ดูระบบจองห้องสาขา https://maejo.link/csmjuroom)
