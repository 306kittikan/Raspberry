# CSMJU Website Dataset

ชุดข้อมูลนี้รวบรวมเนื้อหาสาธารณะทั้งหมดจากเว็บไซต์ **https://gates.csmju.com** (สาขาวิชาวิทยาการคอมพิวเตอร์ คณะวิทยาศาสตร์ มหาวิทยาลัยแม่โจ้) เก็บข้อมูลเมื่อวันที่ 26 กันยายน 2569 (2026-09-26)

## วิธีเก็บข้อมูล

เว็บไซต์สร้างด้วย Next.js และดึงข้อมูลจาก REST API ที่ `https://gates.csmju.com/api/*` ข้อมูลจึงเก็บจาก 3 แหล่ง:

1. **Public API** ดึงครบทุกหน้า (pagination) จาก 21 endpoint ที่เปิดให้เข้าถึงโดยไม่ต้องล็อกอิน และตรวจแล้วว่าจำนวนระเบียนตรงกับ `meta.totalItems`
2. **หน้าเว็บที่เรนเดอร์จริง** (headless Chromium) ทุกหน้าสาธารณะ รวมทุกแท็บของหน้ารายละเอียดหลักสูตร ส่วนนี้ใช้เก็บเนื้อหาที่เขียนไว้ตายตัวในโค้ด frontend และไม่มีใน API เช่น ปรัชญา วิสัยทัศน์ พันธกิจ วัตถุประสงค์ PLO และตัวเลขสถิติในหน้าแรกและหน้าเกี่ยวกับเรา
3. **ตรวจสอบย้อนกลับ** รหัสวิชาทุกตัวในโครงสร้างหลักสูตรและแผนการศึกษาพบบนหน้าเว็บจริง และหน่วยกิตรวมรายภาคเรียนตรงกับที่หน้าเว็บแสดง

ไม่ได้เก็บส่วนที่ต้องล็อกอิน (`/mis/*`, `/dashboard/*`, endpoint `users`, `complains`)

## โครงสร้างไฟล์

```
csmju_dataset/
├── csmju_dataset.json          ← ข้อมูลทั้งหมดในไฟล์เดียว (meta + organization + ทุกตาราง)
├── csv/                        ← 21 ตาราง (UTF-8 with BOM เปิดใน Excel ได้ภาษาไทยไม่เพี้ยน)
├── rag/csmju_knowledge_chunks.jsonl  ← 352 chunks ภาษาไทยพร้อมใช้กับ Chatbot / RAG / embedding
└── raw_api/                    ← JSON ดิบจาก API (ไม่ผ่านการแปลง)
```

## RAG chunks (rag/csmju_knowledge_chunks.jsonl)

1 บรรทัด = 1 chunk มีฟิลด์ `{id, type, title, text, source_url, metadata}` ข้อความเขียนเป็นภาษาไทยที่อ่านเข้าใจได้ในตัวเอง พร้อมนำไปทำ embedding

ชนิดของ chunk: `course` (253), `program_structure` (28), `about` (21), `study_plan` (16), `personnel` (15), `news` (8), `program` / `program_objectives` / `program_plo` (2 ต่อชนิด), `organization`, `contact`, `facilities`, `features`, `project`

## ข้อสังเกตเกี่ยวกับข้อมูลต้นทาง (ควรรู้ก่อนนำไปใช้)

1. **ปีก่อตั้งไม่ตรงกัน:** ไทม์ไลน์ในหน้าเกี่ยวกับเราระบุ "1995" และ "2010" แต่เนื้อหาประวัติใน API ระบุว่าเริ่มตั้งภาควิชาปีการศึกษา 2536 (ค.ศ. 1993) และรับนักศึกษารุ่นแรก 38 คนในปีการศึกษา 2538 (ค.ศ. 1995) ชุดข้อมูลเก็บทั้งสองแบบตามต้นฉบับ
2. **แผนการศึกษามีหน่วยกิตรวมไม่เท่ากับ 120:** หลักสูตร 2565 รวมได้ 114 หน่วยกิต (ปี 4 ภาค 1 ว่าง) และหลักสูตร 2570 รวมได้ 132 หน่วยกิต ตัวเลขนี้ตรงกับที่หน้าเว็บแสดง จึงน่าจะเป็นข้อมูลต้นทางที่ยังกรอกไม่ครบหรือไม่ตรง
3. **program_courses 71 แถวไม่ผูกกับหลักสูตร** (`program_id` ว่าง) เช่น กลุ่มวิชาเอกบังคับ กลุ่มวิชาแกน และวิทยานิพนธ์ ดูเหมือนเป็นข้อมูลค้าง (orphan) ในฐานข้อมูล ถ้าต้องการเฉพาะที่แสดงบนเว็บ ให้กรองแถวที่ `program_id` ไม่ว่าง
4. **ตัวเลขสถิติไม่ตรงกันระหว่างหน้า:** หน้าแรกระบุผู้สำเร็จการศึกษา "1,999+" ส่วนหน้าเกี่ยวกับเราระบุศิษย์เก่าสาย IT "1,000+"
5. **ส่วนที่ยังไม่มีข้อมูล:** events (ปฏิทินกิจกรรม), alumnis (ศิษย์เก่า) และ testimonials มี 0 รายการ ปุ่ม "ทุนการศึกษา" ในหน้าแรกไม่มีลิงก์
6. บุคลากร 5 คนไม่มีโปรไฟล์ละเอียด (`bio`, `expertise` ฯลฯ ว่าง) หน้าเว็บแสดงข้อมูลบุคลากรผ่าน API สาธารณะ
7. เนื้อหา about_sections หมวด ปรัชญา / ความสำคัญ / วัตถุประสงค์ / PLO-SLO (ระดับสาขา) มาจาก API แต่ไม่ปรากฏในหน้า /abouts ตอนเรนเดอร์แบบปกติ และเป็นคนละชุดกับปรัชญาและ PLO ในหน้ารายละเอียดหลักสูตร (ตาราง programs / program_plos)
8. ห้อง "ห้องคอมพิวเตอร์ 3203 จุฬาภรณ์" มีใน API แต่ไม่แสดงในรายการหน้า Facilities ตอนเก็บข้อมูล

## ข้อควรระวังในการนำไปใช้

ข้อมูลบุคลากร (อีเมล เบอร์โทร) เป็นข้อมูลติดต่อที่สาขาเผยแพร่สาธารณะ ถ้าจะนำไปเผยแพร่ต่อหรือใช้เชิงพาณิชย์ ควรขออนุญาตสาขาวิชาก่อน เว็บไซต์ตั้ง `meta robots=noindex` ไว้ด้วย

## อัปเดตข้อมูลใหม่

ดึงข้อมูลล่าสุดได้โดยเรียก API โดยตรง เช่น `GET https://gates.csmju.com/api/courses?page=1&limit=100` (ทุก endpoint ส่ง `{data, meta:{totalItems,totalPages}, links}` ยกเว้น `nav-items` ซึ่งส่งเป็น array)
